This program guarantees that no deadlock occurs by utilizing the synchronization block to ensure that 
only one thread can retrieve and unlock locks on the grid at a time, while all other threads are blocked off
and wait to access the synchronized block after generating its possible moves. As this program also ensures that
the same cells are not revisited when iterating through the grid, each thread that accesses the synchronized
block would not encounter deadlock, and no other thread can enter that section of the code, guaranteeing 
that no other thread can retrieve any locks on the grid until that thread has finished iterating through
its generated possible moves. As in addition, each thread attempts to retrieve all locks before execution and if this is not
possible, it would wait until it can acquire the locks, this eliminates no preemption. Thus, deadlock will never occur.
